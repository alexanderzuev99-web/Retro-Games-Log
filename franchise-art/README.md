# Franchise character artwork

37 portraits were generated with the built-in image generation tool in a simplified 16-bit style. For 18 characters whose generation was unavailable after retries, existing game sprites are used instead.

## Existing game sprite credits

Characters and game graphics remain the property of their original creators, developers and publishers (including Nintendo, HAL Laboratory, Game Freak, Marvel, Disney/Pixar, Warner Bros., DreamWorks, Lucasfilm and their respective game developers). This is a personal, non-commercial game library. Source archives and sprite contributors are credited below.
