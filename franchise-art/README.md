# Franchise character artwork

The active set contains 37 generated portraits, 10 generated franchise symbols, and 8 existing game sprites. Generated artwork uses the built-in image generation tool and a simplified 16-bit style. The symbols replace earlier portraits of Harry Potter, Star Wars, Super Mario, Zelda, Donkey Kong, Pokémon, Metroid, Looney Tunes, Pixar, and Totally Spies!.
