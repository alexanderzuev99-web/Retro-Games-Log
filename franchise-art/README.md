# Franchise character artwork

The active set contains 37 generated portraits, 15 generated franchise symbols, and 3 existing game sprites. Generated artwork uses the built-in image generation tool and a simplified 16-bit style. The symbols replace earlier portraits of Harry Potter, Star Wars, Super Mario, Zelda, Donkey Kong, Pokémon, Metroid, Looney Tunes, Pixar, and Totally Spies!.

## Existing game sprite credits

Characters and game graphics remain the property of their original creators, developers and publishers (including Nintendo, HAL Laboratory, Game Freak, Marvel, Disney/Pixar, Warner Bros., DreamWorks, Lucasfilm and their respective game developers).
